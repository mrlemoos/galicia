# Spend less. Keep meaning.

Context is working memory. Tokens, tool calls and attention are finite. Galicia removes redundant work while preserving evidence needed to trust the result.

- Load relevant context on demand. Root map routes to domain owners; no blanket document ingestion.
- Ask decisions humans own. Find facts agents can inspect. Preserve accepted answers.
- Use targeted reads. Strip progress noise; retain diagnostics and a route back to raw evidence.
- Reuse findings until inputs change. Repeat checks for new evidence, failures or material uncertainty.
- Match verification to consequence. Never cut security, data-loss prevention, accessibility or requested checks.
- Recommend small-model subagents for scoped ADR research/review. Name evidence required; delegate only when authorised.
- Keep instructions short enough to inspect. Negation, conditions and uncertainty matter more than word count.
- Measure instruction tokens separately from output, reasoning, cached input, latency, retries and task quality. Count whole workflow overhead, including hooks and setup context.

Terse output does not prove cheaper hidden reasoning. Prompts can request concise work; platform/model controls determine available effort settings. No automatic effort downgrade. Safety and correctness win when compression conflicts with meaning.

No emojis. No mandatory proxy. No external tracker. No automatic spec deletion. Expand only when a real task needs it.
